# Publishing a release

1. Build and test against a compatible desktop LiveSplit installation using the scripts in this repository.
2. Commit the source, tests, README, changelog, and matching `dist/LiveSplit.GoldClip.dll`.
3. Create a release tagged `v0.9.6` at that commit, titled **Auto Clip Golds v0.9.6**.
4. Mark it as a **prerelease**.
5. Attach `LiveSplit.GoldClip.dll` and `Auto-Clip-Golds-v0.9.6.zip` containing the same DLL and README.
6. Verify the published release is a prerelease and both downloads are present.

Do not include local test workspaces, personal layouts, passwords, logs, recordings, earlier diagnostic builds, or DLL backups.

No license has been selected for this code. The external projects linked in the README retain their own licenses.
